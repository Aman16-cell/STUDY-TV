# StudyTV
A remote-friendly Pomodoro timer and daily task list designed for the TV screen.

Live demo: https://aman16-cell.github.io/STUDY-TV/

How to run: open index.html in any web browser. No installation needed.

Controls: Arrow keys to move, Enter/Select to press, Play/Pause to start or pause the timer, Esc/Back to return to the Start button.

Built with HTML, CSS and JavaScript (Web Audio API, localStorage).
